# AEMobile 图标库

AEMobile 是 GTNH 的手机端物品终端。这里放它的**图标数据**：物品图标、流体图标、神秘时代源质图标。

App 装好就能用，不需要你手动下载任何东西 —— 这个仓库是给 App 自动更新用的。

| 库 | 内容 | 大小 |
|---|---|---|
| 物品 | 6 万多个物品的图标和中文名 | ~186MB |
| 流体 | 流体名字、流体和容器物品的对应关系 | ~216KB |
| 源质 | 神秘时代要素的图标和名字 | ~180KB |

三个库**分开更新**：哪个变了才下哪个，不会因为补了一个源质图标就重下 186MB。

---

## 一、怎么更新图标

App 里点几下就行，不用重装、不用重启：

1. 打开 AEMobile → 底部 **设置**
2. 点 **图标库**
3. 点 **检查更新** —— 三个库里哪几个变了会标出「可更新 → 版本号」
4. 点 **下载并安装**

装完当次生效。想省空间可以点 **恢复内置图标库**，回到随安装包分发的那份。

> 更新源默认走这个仓库，不用改。除非有人给了你别的地址。

---

## 二、游戏里的指令

指令是**客户端**指令，单人/联机都能用，不需要管理员权限。自己导出图标时才用得上。

| 指令 | 作用 |
|---|---|
| `/aemobile dumpicons` | 导出全部注册物品的图标（含所有 meta），128px |
| `/aemobile dumpicons 64` | 同上，图标 64px（体积减半） |
| `/aemobile dumpicons list` | 只导出清单里列出的物品（补漏用，秒级） |
| `/aemobile dumpicons list 64` | 同上 + 指定尺寸 |

**用法**：进游戏 → 进世界 → 等 NEI 物品面板加载完（不再显示"加载中"）→ 敲指令。

导出期间画面会花屏（和 NEI 自带的图标导出一样，正常现象），几秒到几十秒。
按 **Esc** 可中止，已经导出的不会丢。

**产物**：

```
<游戏目录>/dumps/aemobile/items/<modid>/<item>_<meta>.png
<游戏目录>/dumps/aemobile/items/manifest.jsonl
```

这些文件可以直接交给维护者合并进图标库。

## 三、常见问题

**Q：物品页有几个图标是空白的？**
A：说明那个「物品名 + meta」还没被导出过。等维护者更新，或者你自己跑一次
`/aemobile dumpicons list` 补上再把文件交给维护者。

**Q：流体和源质在「可合成」筛选里看不到？**
A：它们本来就不可合成。第一行点开「流体」「源质」，第二行切到「全部」。

**Q：搜索搜不到流体/源质？**
A：搜索按**显示名**匹配，直接搜中文就行（比如「氨」「火」）。也支持按注册名搜
（`fluid_drop`、`essentia`）。

**Q：图标库占多大空间？**
A：内置的随 APK 走不额外占；在线包最多再占一份（约 186MB）。设置页能看到占用，也能一键清掉。

**Q：更新失败/一直转圈？**
A：先确认网络能打开这个仓库的 raw 地址；也可以在设置里把更新源换成镜像。实在不行点
「恢复内置图标库」，用安装包里自带的那份。

